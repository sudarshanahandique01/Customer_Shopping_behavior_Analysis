This project focuses on analyzing customer shopping behavior data to identify purchasing patterns, customer preferences, subscription trends, and revenue insights. I performed data cleaning and preprocessing using Python, stored the processed data in PostgreSQL, and created an interactive Power BI dashboard for visualization and business analysis.

TECH STACK USED:
Python — Used for data analysis, preprocessing, and database integration.
pandas — Used for data cleaning, transformation, and manipulation using DataFrames.
NumPy — Used for numerical and mathematical operations during analysis.
Jupyter Notebook — Used to write, execute, and test Python code interactively.
PostgreSQL — Used to store and manage processed customer data.
SQLAlchemy — Used to simplify database connection and data loading operations.
psycopg2 — Used to connect Python applications with PostgreSQL database.
Power BI — Used to create interactive dashboards and visualize business insights.
